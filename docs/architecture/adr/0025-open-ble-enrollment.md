# ADR 0025：蓝牙范围内开放新电脑加入

状态：实施中。日期：2026-11-05。

根据用户要求，盒子已被其他电脑绑定后，新电脑也可通过蓝牙直接加入，无需配对密钥。新增协议模式 open，保留 claim、join、resume 的既有语义。新电脑证明其私钥，盒子追加其受限 SSH 公钥，不覆盖已有电脑；主机签名和加密会话仍按原协议处理。

此模式没有用户身份认证或物理确认：任何蓝牙范围内的设备都可以取得持久的受限隧道、配置盒子 Wi-Fi 并使用盒子模型。撤销某个公钥或令牌无法阻止其再次加入。首次连接的主机身份仍是首次使用信任，无法抵御附近主动冒充设备。这是明确接受的产品安全取舍；不能把该机制描述为访问控制。受限 SSH 仍不得执行命令或接触审批凭据，模型上游密钥不会下发。
