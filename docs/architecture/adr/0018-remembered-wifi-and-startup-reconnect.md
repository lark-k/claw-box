# ADR 0018：复用已保存 Wi-Fi 和启动时恢复无线地址

状态：采纳。日期：2026-10-17。

Wi-Fi 密码继续仅保存在板子 NetworkManager 的 root-only keyfile，Windows 不另建密码库、不回读或显示密码。扫描结果增加 saved 标记，限于本服务成功持久化的个人网络配置。已绑定所有者可以显式 connect_saved，按原始 SSID 和安全类型匹配配置；不接受文件路径、命令或凭据导出。密码改变时用户输入新密码，仍沿用先临时激活、成功才替换的事务，不破坏原可用配置。

盒子 NetworkManager 在启动和网络恢复时自动连接已保存网络。App 启动沿用原配对自动尝试业务连接：先只读核验原地址，地址失效时通过已认证 BLE status 获取无线地址，再严格验证同一 SSH 主机身份并更新端点。此恢复过程不调用 configure、connect_saved、claim 或 desktop_setup，不重放写操作或任务。手动停止可取消发现、等待和连接，恢复失败保留配对及历史，允许向导重试。

新旧协议兼容：saved 缺失视为未知，旧服务继续支持手输密码和使用当前 Wi-Fi。没有保存记录时不猜测密码，也不从 Windows 的其他 Wi-Fi 配置提取凭据。

0.3.26 修正换网失败边界：无线地址恢复整体限时 30 秒，每次 SSH 地址探测最多 4 秒；无法获得可用地址时返回需要设置网络的状态。启动及首页连接失败后弹出提示，由用户选择“设置 Wi-Fi”或“暂不连接”；手动停止或关闭主窗口时不弹出恢复窗口。连接边界捕获 SetupException 和蓝牙系统异常，恢复失败不会退出 App，不会修改原配对或自动提交新网络配置。
