# ADR 0007：流式回复的过程与结果呈现

状态：采纳。日期：2026-10-14。

当前兼容聊天入口把多段阶段说明与最终答复串在同一内容流中，APP 原来直接追加到正文，完成后不能折叠这些阶段说明。保持现有 HTTP/SSE、认证、审批和工作区边界，不新增远端任务、额外模型调用或写入重放。

每轮提示约定阶段说明以 `[[QH_PROGRESS]]` 开头，最终答复以 `[[QH_FINAL]]` 开头。客户端增量解析，支持标记跨任意分片边界，标记不显示在界面。对未遵循约定的旧输出，实际工具请求之前已收到的正文归入处理过程；没有工具的普通答复完整保留。只有过程标记而没有最终答复时，不把过程文字自动当成成功结果。中断后的部分结果保留在过程详情，并显示既有结果未知说明。

阶段条目与工具回执作为会话 JSON 的可选新增字段保存；旧记录没有字段时使用空集合。展示概要限 80 字，原始公开阶段文字在详情内保留。计时、运行标记、审批等待和展开状态均不持久化；运行时展开，结束时强制折叠，结束后允许用户自行展开。状态灯只表示本次等待仍在进行，不代替实际工具成功回执。

参考：[OpenClaw 兼容聊天入口源码](https://github.com/openclaw/openclaw/blob/main/src/gateway/openai-http.ts)与[流式入口说明](https://github.com/openclaw/openclaw/blob/main/docs/gateway/openai-http-api.md)。客户端不依赖特定版本才有的 WebSocket 事件或额外 operator 权限。
