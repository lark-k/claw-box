# ADR 0017：桌面有线、无线和换板入口分离

状态：采纳。日期：2026-10-17。

设置菜单提供“有线连接”“无线连接”两个日常入口，与独立分组的“更换板子／重新绑定”区分。网络切换保留原主机身份、专用密钥、执行器凭据、聊天和工作区；不得将网络错误引导为换板或重置配对。任务运行或待审批时禁止变更连接。

Windows WPF 直接使用 WinRT BLE API，不要求外部 Python。客户端实现 ADR 0016 的签名握手和加密协议，复用原 Ed25519 隧道私钥；发现广播与 mDNS 仅定位地址，必须核验既有 SSH 身份。选择未绑定设备时才允许显式首次信任；有已保存身份时不能接受不同板子。响应丢失不自动重发网络写入。

有线和无线各保存最近成功端点及当前选择；每次只运行一条业务连接。切换前核验目标身份，成功后提交选择，失败保留原配对和可恢复端点。无线使用蓝牙配置并取回地址，不依赖旧 Wi-Fi；蓝牙不可用时可使用已保存无线地址连接，或手动输入同局域网地址，经原身份验证后使用。首次/失败启动进入连接方式选择页，不将无线用户送进以太网 IP 或共享检查。

无密码首次无线绑定需要在板子完成固定桌面初始化。为已认证所有者新增加密 desktop_setup 操作：只接受严格校验的 worker token，调用交付镜像内固定版本的插件和桌面配置脚本，返回私有聊天网关凭据。不接受源码、命令或任意路径，不传 admin token，不注册智能体工具。已存在配对的换网不调用此操作；中途首次绑定使用已保存的专用私钥和主机身份恢复，不重新 claim、不换密钥。初始化必须由明确“连接并开始使用”操作触发，重启不自动重放。

便携发布保留 .NET 自包含运行时，并包含 Windows SDK 投影；BouncyCastle 版本与现有 SSH.NET 依赖统一。新增协议互操作、身份拒绝、取消、端点切换和清晰入口的测试，真实 BLE/无线连接验证与截图验收后发布新版本。
