# ADR 0028：用户开启的电脑热点

状态：已由 ADR 0029 取代。日期：2026-11-06。

当电脑和盒子无法通过当前 Wi-Fi 互访时，界面指导用户在 Windows 设置中开启共享当前网络的 2.4 GHz 移动热点。用户明确选择切换后，桌面进程读取系统当前热点名称和密码，仅在现有已认证加密蓝牙会话的配网流程中将其发送至已核验的盒子；凭据不通过界面或日志传递。软件不自动启停热点、不修改热点设置、不自动重放配网写入。盒子成功取得地址后，仍需核验 SSH 身份及模型服务，才宣称网络连接成功；失败提供可见提示。用户关闭热点会影响此网络通道。

热点能力受 Windows、无线驱动、策略以及共享网络限制；盒子仅支持 2.4 GHz。此路径改变盒子的当前 Wi-Fi，保持电脑原有上网连接依赖 Windows 热点共享能力。用户应在当前模型请求结束后操作，以免中断请求。
