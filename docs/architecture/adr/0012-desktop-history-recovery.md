# ADR 0012：损坏聊天记录的启动隔离与持久保存

状态：采纳。日期：2026-10-15。

真实 Windows 崩溃日志确认，0.3.15/0.3.16 在启动读取单条聊天 JSON 时，未处理的 JsonException 直接终止进程。用户异常重启后的一份聊天文件全部为零字节，索引和设置仍有效。连接探测和 mock 界面渲染未覆盖真实历史加载。

单条聊天文件格式损坏或丢失时，优先读取同路径的上一份有效备份；两份均不可用则保留索引身份，返回带固定说明的只读占位会话。占位不会写回损坏文件，不能发送任务或重命名；用户可新建会话继续使用。会话身份与索引不一致及路径链接等安全检查仍拒绝加载，不借恢复放宽。没有有效副本时明确表示内容尚未恢复，不能伪造聊天内容或把旧的无关会话作为恢复结果。

本机 JSON 保存先创建独占临时文件，写入后 Flush(true)，再原子替换目标并保留上一份有效 JSON 为 .bak。现有文件损坏时不把它替换成有效备份；覆盖前另存原始损坏字节。写入和备份均拒绝路径链接。该方式降低异常关机的数据丢失风险，不保证硬件故障下零损失。

此变更仅涉及 Windows 私有本地记录；配对身份、凭据角色、SSH 传输、任务恢复与逐请求审批保持原约束。历史恢复不发送聊天，不重新授权或重放工具请求。启动失败提示不能泄露记录中的任意文本。
