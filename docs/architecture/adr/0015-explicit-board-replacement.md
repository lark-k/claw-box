# ADR 0015：显式更换板子与重新绑定

状态：采纳。日期：2026-10-17。

设置按钮打开独立菜单，分别提供日常“连接向导”和“更换板子／重新绑定”。换板先显示专用确认窗口，说明会断开当前连接、停止使用旧配对，但保留本机聊天、工作区、用户文件与执行器审计。只有用户明确确认后才切换；任务运行、连接进行中或存在待审批请求时禁止换板。

确认换板后，为当前设置生成新的随机配对编号，指向应用私有 connections/replacement-<编号>/ 下尚未创建的配对和网关文件。该编号持久保存，取消向导或重启 APP 后继续使用同一待绑定位置，不自动恢复旧配对、不自动接受新设备身份，也不重放任务。旧配对文件原样保留但不再作为当前配对；导入的外部文件不删除、不移动。保存设置失败时恢复原配对选择。

普通绑定继续使用按地址和端口组织的现有目录；只有显式换板才使用新的独立目录。配对编号必须为规范的小写 GUID，不接受任意路径。新目录沿用当前用户 ACL、路径链接拒绝和现有凭据校验。即使新旧板地址相同，也不会覆盖旧 known_hosts 或复用旧隧道私钥。新身份仍经连接向导中的设备确认、临时密码登录和 SSH/SFTP 指纹校验建立，后续继续严格检查主机密钥。

换板会释放 APP 自己拥有的连接和执行器、清除内存中的设备检查缓存，保留本机执行器凭据及权限偏好；仅 worker 凭据进入板子。操作只改变本机当前配对选择，不宣称撤销离线旧板上的公钥或凭据。确认后回到现有连接向导，用户无需手工清理文件或生成密钥。
