# ADR 0009：桌面内首次连接与诊断

状态：采纳。日期：2026-10-14。

新用户在 Quantum Harness 中完成网络检查、可信指纹核验、临时管理登录、受限密钥配对、插件部署和连接验收。首次启动缺少配对文件或连接失败时打开引导；设置保留已有配置导入，并提供再次诊断入口。

首次配置使用 SSH.NET 的密码 SSH/SFTP，会话仅存在于引导窗口内。密码不进入参数、日志、磁盘、模型或设置。SSH 与 SFTP 都仅协商 Ed25519 并以用户从交付卡/可信管理员取得的 SHA256 指纹核验；网络扫描不建立信任。日常连接继续使用 Windows OpenSSH 与既有受限专用密钥，不新增监听接口、任意工具或审批权限。

无凭据的本机与 TCP 检查定时复查，认证检查由用户点击触发。绑定按钮说明具体部署行为：仅发送 worker 凭据、安装随软件打包的固定插件/配置程序、更新指定隧道密钥和重启网关。板子必须符合当前 root 管理的 OpenClaw 镜像条件；缺少模型、认证或工具策略时停止并说明处理办法，不自动降低策略。

沿用当前 Windows 用户私有目录、ACL 与凭据格式。已有凭据不重新生成，已有配对不得隐式改主机指纹。配对文件在配置成功后激活；中途失败保留专用密钥以便用户显式重试，取消/重启不会自动继续远端配置，也不重放任何文档任务。远端既有安装器的校验与回退继续生效，跨多个步骤不承诺整体事务回滚。

验收区分网络可达、板子条件通过、配置完成和实际聊天入口可用；网络可达不能证明服务或远端模型可用。最终健康检查不发送模型任务。远端模型的实际推理由首次聊天验证。

参考：[SSH.NET 官方 API](https://sshnet.github.io/SSH.NET/)、[现有连接协议](../../api/box-connection-v1.md)。
