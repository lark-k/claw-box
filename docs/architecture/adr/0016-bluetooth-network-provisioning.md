# ADR 0016：无配对码蓝牙配网与离线改网

状态：采纳。日期：2026-10-17。

## 决策

板子交付镜像预装 RTL8723DU 驱动、BlueZ、NetworkManager 和独立的蓝牙 GATT 配网服务。桌面界面另行实现，本次不改变桌面连接流程。服务只提供状态、扫描、首次绑定和 Wi-Fi 配置，不注册智能体工具，不暴露执行器、任意命令、文件路径或审批凭据。

不使用二维码、人工配对码或 root 密码。新设备由用户在客户端显式选择，首次采用 TOFU；此方式无法凭空证明机身归属，首次绑定存在附近设备抢先绑定的边界。绑定完成后仅允许已登记专用 Ed25519 公钥持有者操作，网络不可用和重启不会重新开放首次绑定。现有 authorized_keys 中标注 clawbox-reverse-tunnel 的受限专用密钥直接作为已绑定身份，撤销该密钥同步撤销蓝牙改网权限。

BLE 是常驻的维护通道，已绑定设备换网不依赖旧 Wi-Fi、IP、网线或互联网。Wi-Fi 仍承载 SSH 和业务。广播只含服务 UUID、短设备名，不广播密码或凭据。蓝牙链路无需系统 PIN，应用协议必须独立加密和认证；不将 BLE 地址、信号强度或设备名作为授权凭据。

板子复用 SSH Ed25519 主机密钥签名握手，客户端首次选择后保存主机身份；已有客户端必须匹配已知主机密钥。每个蓝牙连接使用临时 X25519、HKDF-SHA256 派生独立双向 AES-256-GCM 密钥。握手绑定双方随机数、临时公钥和板子身份；客户端用专用 Ed25519 密钥签名握手，服务重新检查 authorized_keys。加密请求使用严格递增序号，绑定会话和方向，禁止重放、跨会话和跨设备复用。断开、超时和重新握手清除会话。首次登记只允许一个持有者，写入的 SSH 权限沿用 loopback 转发限制，不授予 shell。

NetworkManager 通过系统 D-Bus 管理 Wi-Fi。验证参数后创建临时内存配置，连接成功才持久化；失败删除临时配置并尝试恢复原无线连接，不修改以太网。保留其他已保存 Wi-Fi 供返家自动连接。断电和重启不自动重放配网写请求。错误只返回稳定错误码，不向日志、进程参数或蓝牙响应输出密码。单次网络变更串行执行，限制消息长度、会话数和寿命。

通过 Avahi 发布 _clawbox._tcp 的 SSH 端口及公开身份，方便客户端在无线地址变化后发现设备；发现信息不构成身份信任，连接时仍严格验证 SSH 主机密钥。Windows 执行器继续只监听 loopback，worker 不得批准请求。

## 验证

覆盖已有配对、首次登记、撤销、签名与加密篡改、重放、片段隔离、断线清理、错误密码回退和敏感信息排除。实机验证驱动、无线扫描、BlueZ 广播和 Windows BLE GATT 调用；实际联网和异地改网需要测试 Wi-Fi。安装、回退与验证结果记录在开发文档中。
