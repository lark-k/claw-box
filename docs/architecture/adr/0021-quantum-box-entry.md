# ADR 0021：以盒子连接入口替换官方账号登录

状态：采纳。日期：2026-11-03。

Quantum 构建不注册官方账号菜单、登录引导、余额及充值页面，也不订阅账号状态或发起官网登录。原上游账号实现保留供上游维护，Quantum 客户端在注册阶段选择独立的盒子界面。模型提供商、工具和权限模块继续使用原实现；其他提供商的 API Key 配置保留。

盒子入口同时位于侧栏“更多”和设置页。当前只保存待连接的主机地址及 SSH 端口，存储于现有 Host settings 文档的 `ui-settings-account` 命名空间，新增可选 `boxHost` 与 `boxSshPort`，不改变已有字段。配置不包含凭据。主机地址及端口由界面和 Host schema 双重校验，更新采用现有 ConfigForm 的原子 revision 写入。

保存配置不建立网络连接、不修改模型路由，也不表示配对完成。实体盒子不可用期间界面始终说明尚未连接；连接认证、主机身份核验和转发授权按 ADR 0020 在实机阶段实现。开发服务器直连仍可使用。

回退只需移除 Quantum 覆盖并切回原构建；盒子配置字段保持可选，旧账号凭据不会被删除或上传。
