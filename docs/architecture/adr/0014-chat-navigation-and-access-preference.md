# ADR 0014：聊天定位与权限偏好记忆

状态：采纳。日期：2026-10-15。

按用户要求，Windows 当前用户的权限选择保存在已有 desktop/settings.json 的 AccessMode 字段。只接受 approval、readOnly、fullAccess，缺失或未知值使用 approval。切换对话、工作区、连接和重新启动保留用户明确选择，按钮的标签、图标与颜色来自同一状态。替代 ADR 0006 中重启及切换工作区重置权限的产品约定。

偏好记忆不恢复执行请求。新连接建立前已经存在的 pending 请求只能手动核对；完全访问自动审批仅处理本次连接开始后新创建、未过期的确切请求，每个请求仍独立提交管理员审批摘要，失败不自动重试。不扩大工作凭据权限、路径范围或允许工具，不重放 interrupted 任务。

聊天首次进入和切换会话在布局完成后定位最新消息。靠近底部时跟随新消息和流式增长；向上阅读或点击左侧消息定位后保留阅读位置，显示返回最新按钮。消息预览仅展示当前对话内存中的内容，不增加网络请求或另存历史内容。滚动条使用无端点箭头的细圆角滑块，悬停和拖动加深颜色。
