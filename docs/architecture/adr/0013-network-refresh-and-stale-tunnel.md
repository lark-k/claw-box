# ADR 0013：网络配置刷新与失效隧道回收

状态：采纳。日期：2026-10-15。

以太网检查读取 Windows 实体 PCI/USB 网口的手动 IPv4 配置，优先同网段网口，过滤蓝牙、虚拟接口及过滤器子接口；界面只显示所用网口和一组地址/掩码。手动配置正确不代表链路、SSH 或模型服务一定可用，后续项目独立验证。

网络地址变化事件、用户从网络设置返回及短周期检查触发即时只读复查。模型网络未通过时，在保留于窗口的本次密码有效期间重查模型端口，不重复部署；失败密码不定时重试。输入改变与窗口关闭撤销旧检查。

显式“绑定并连接”允许执行固定的旧隧道恢复程序：仅限板子 loopback 18791 的 sshd 会话，远端对端必须是当前已认证的 Windows 地址，其源端口必须已不存在于 Windows 当前活动 SSH TCP 连接列表。活动列表须包含本次管理会话且新鲜；不满足任一条件就保留占用者。发送终止信号前再次核验 PID 创建标记和套接字。不会按端口杀未知进程或终止其他电脑的连接，不扩大专用密钥权限，不自动发送文件任务。

专用隧道密钥保持禁止 shell。日常无密码连接无法证明远端占用者时仅报告需在引导显式绑定修复，不冒充占用已被回收。恢复程序只随用户明确绑定使用临时管理会话执行，不保存密码。

正常运行隧道改为由 APP 内 SSH.NET 对象管理，保留同一专用私钥、Ed25519 主机身份和 loopback 本地/反向转发。退出时先显式停止两种转发，发送远端撤销监听请求，再 Disconnect/Dispose；最后结束本机执行器。不再通过直接杀 OpenSSH 子进程作为正常断开方式。意外断电仍可能残留服务器会话，不能宣称正常关闭流程覆盖物理断电。
