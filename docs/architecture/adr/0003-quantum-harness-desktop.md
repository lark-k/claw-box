# ADR 0003：Quantum Harness 原生桌面入口

状态：采纳。日期：2026-10-13。

采用 .NET 10 WPF 原生 Windows APP，名称 Quantum Harness。按用户要求直接在 main 开发。参考图用于浅色三栏布局、导航、聊天与输入框的视觉依据；产品功能沿用已实现的工具与审批边界。

APP 启动自己的执行器进程与 OpenSSH 进程，窗口隐藏；不终止其他实例，不替换其他监听者。执行器继续监听 loopback，管理员凭据由 APP 读取 Windows 私有用户目录，不能传入模型。审批卡片显示不可变原始参数及摘要，点击决定时使用该摘要。

SSH 继续反向转发工具端口，并新增本地转发 127.0.0.1:18889 → 盒子 127.0.0.1:18789。专用密钥只新增对该网关端口的 permitopen，仍不能执行 shell。盒子启用认证的 /v1/chat/completions；APP 使用网关 operator token，通过隧道发送 SSE 聊天请求。网关 token 保存在 Windows 私有目录，不是模型 Key，也不是执行器管理员 token。单用户可信盒子的边界与 ADR 0002 一致。

对话存于 Windows 私有目录，每个对话使用稳定 session key 与独立历史。请求发送后不重试，断线与取消标记结果未知；停止按钮取消客户端等待，并尽力取消待审批/执行器任务，不宣称能撤销已完成写入或停止远端全部推理。重启不重新发送对话。

程序按便携包发布，包含自包含 APP 与 executor 子目录；无需开发 SDK。连接配对和网关凭据可沿用现有机器配置；新增设备需按配对指南配置。首版不提供多用户、任意命令执行或无审批办公。

Native WPF 的视觉验收使用应用自身渲染截图与参考图比较，报告放在 docs/development/；不另建网站或 Vite 项目。图中无业务图片资产，使用 Windows 自带 Fluent 图标字体库和系统中文字库，不生成无关图片。
