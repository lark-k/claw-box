# ADR 0026：盒子多模型发现与路由

状态：实施中。日期：2026-11-07。

盒子维持回环监听与既有配对认证。私有配置登记有限的上游地址和独立密钥；网关并行查询各上游 `/v1/models`，以服务器标识和模型 ID 组成公开 ID，避免同名模型路由冲突。目录短暂缓存；不可用上游不进入结果，模型换名后在刷新时更新。请求仅按目录中实际存在的 ID 路由到固定配置的上游，替换请求中的 model 字段，其余内容和流式响应保留；失败不自动重放。目录成功不代表推理或工具调用能力已验证。

现有单上游配置继续按原方式透传，配对和凭据协议保持不变。桌面通过已有认证隧道拉取模型目录并更新模型提供商，用户使用现有模型选择入口；服务器密钥只保留在盒子。模型使用盒子私有配置的上下文长度，声明文本和图片输入；音视频能力不由此声明。模型能力和上游兼容性需要实际验收。

允许 HTTP 必须继续显式配置；公网 HTTP 不提供保密性，部署应使用 HTTPS 或受保护的网络。升级必须保留私有配置和回退文件，避免影响已有配对。上游地址或认证变更需由管理员更新私有配置。
