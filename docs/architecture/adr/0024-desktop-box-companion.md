# ADR 0024：Quantum 桌面盒子连接组件

状态：实施中。日期：2026-11-05。

Quantum Electron 应用通过受限的本机子进程复用 Windows 原生蓝牙、SSH 和私有目录能力。子进程通过父进程专用 stdin/stdout JSON 消息接收固定操作，不提供通用 shell，也不监听网络端口。BLE 地址及设备指纹仅用于配对和身份验证；SSH 隧道绑定本机动态回环端口，断开时关闭。配对密钥只在首次加入时使用，不持久化。

每台电脑生成独立的 Ed25519 私钥。设备地址、已核验主机指纹、模型 ID 和电脑专用网关凭据保存在当前用户私有目录，文件写入采用原子替换；不能覆盖损坏或属于其他设备的现有记录。界面配置模型时使用既有 Host 配置与凭据接口，只写 Quantum 专用模型提供商，不写或下发盒子的上游服务器凭据。配对密钥及登录密码不得进入命令行、日志或安装包。

无线首次连接继续通过 BLE 配网和认证；加入已配对盒子需设备配对密钥。已联网设备也可通过有线或同网段地址和盒子管理员密码完成首次授权。此实施前需要按实际设备和新旧客户端验证，以及完成安装包的运行时、升级和无凭据验证。
