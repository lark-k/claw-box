# ADR 0006：桌面对话数据与工作区生命周期

状态：采纳。日期：2026-10-14。

侧栏以项目与最近两类展示会话，每个会话绑定自己的 Windows 工作区。项目清单独立持久化，移除项目仅隐藏目录；其会话移入最近，重新添加目录后可恢复分组。默认工作区为应用 workspace 下的 yyyy-MM-dd/会话 UUID，聊天记录另存于私有 desktop/chats/yyyy-MM-dd/UUID.json，方便按日查找。

旧 conversations.json 在成功写入新会话文件及索引后移除。删除会话只删除索引中对应的私有 JSON（含活动与差异记录），不递归删除工作区、附件、成果或执行器审计。拒绝穿越、链接和重解析点。盒子远端上下文由 OpenClaw 管理，本次不新增未经验证的远端删除协议；执行器审计亦保留。

变更记录以用户确认的请求与本机执行器成功结果关联。文本修改保存有界前后快照并生成逐行差异，二进制、超限或无法验证的内容只报告文件操作，不能捏造增删行数。工具活动折叠显示在每轮回复上方，最终回复下方列出该轮文件变更。

审批卡位于输入框位置，仍绑定完整参数、摘要和有效期。访问菜单提供只读、逐请求审批与完全访问：只读禁止批准修改及项目运行，每次读取仍须单独批准。用户明确选择完全访问后，本机 APP 用管理员凭据逐个批准已校验的请求，盒子 worker 不获取授权能力，AllowedRoots 与参数校验不变。不提供命令前缀永久授权；重启、重连和切换工作区撤销完全访问。上下文指示显示本地文字估算，服务端未提供窗口容量与完整历史用量时不显示虚构百分比。
