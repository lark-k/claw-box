# ADR 0026：局域网隔离时的蓝牙模型通道

状态：已由 ADR 0029 取代。日期：2026-11-05。

盒子随用户移动时，电脑和盒子即使连接相同 Wi-Fi，也可能处于不同网段或被禁止互访。优先保留经过身份核验的 SSH 模型隧道；网络建连失败且蓝牙仍在附近时，使用已有加密 BLE 会话建立备用本地模型通道。

备用通道仅连接盒子 `127.0.0.1:18792`，不接受目标地址、端口或命令，不转发 SSH、不执行 shell。模型网关仍验证本机独立令牌并限制 HTTP 方法和路径。电脑监听动态回环端口；BLE 加密握手校验盒子身份，每个会话最多一条受限流，设大小、空闲和并发上限。断开或认证撤销时关闭流；丢失写入结果不自动重发。对话请求、工具调用和 Wi-Fi 配置不自动重放。流量受蓝牙带宽限制，使用仍要求盒子可以访问上游模型服务。

BLE 设备必须在范围内；网络需要门户登录或上游不可达时不能保证对话成功。现有 open 设备加入的风险仍按 ADR 0025 适用。
