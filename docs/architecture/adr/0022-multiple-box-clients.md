# ADR 0022：一台盒子授权多台电脑

状态：实施中。日期：2026-11-05。

一台盒子可保留多台电脑各自的受限 SSH 公钥，新增电脑不得覆盖既有密钥。保留 v1 的首次 claim 和已登记设备 resume；新增 join 模式供后续客户端使用。join 使用盒子管理员事先设置的高熵配对密钥，在现有加密握手中以 HMAC 证明双方持有密钥，绑定整个握手和新电脑的独立公钥，不在 BLE 上传输密钥明文。配对密钥位于板端受限目录，可轮换；仅授权拥有它的用户加入，重启服务不会自动开放匿名配对。旧客户端需升级后才能使用 join。

登记密钥沿用现有限制，仅增加盒子本机模型网关的 127.0.0.1:18792 转发权限。现有密钥原样保留，模型网关授权及电脑端转发必须另行实施和验证，不能将 BLE 登记等同于模型连接成功。Wi-Fi 配置、SSH 主机密钥和已有设备数据不作重置。部署前备份服务源码并验证启动，失败恢复旧版本。

网关继续绑定回环地址，模型服务器凭据仅保存在盒子私有配置；桌面自动配置、完整安装包及有线/无线端到端测试属于后续实现，不能视为当前已完成。

板端已支持在受认证 BLE 会话内为每把电脑公钥签发独立的随机网关令牌，令牌存放于盒子 root 私有状态文件；网关在每次请求时读取状态以支持令牌撤销。模型信息仅返回模型 ID、网关端口与本机令牌，禁止返回上游服务器凭据。保留独立的管理测试令牌以兼容现有网关；正式交付需明确轮换和注销策略。管理界面及自动配对还需实现。

当前 join 密钥是高熵长期共享秘密。撤销已知晓该秘密的设备后必须轮换该秘密，否则该设备仍可用新密钥再次加入；未来的用户交付应补充设备管理和撤销机制。
