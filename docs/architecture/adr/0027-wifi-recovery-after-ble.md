# ADR 0027：蓝牙连接后恢复 Wi-Fi 模型通道

状态：已由 ADR 0029 取代。日期：2026-11-06。

当局域网连接暂时不可用而蓝牙备用通道已经建立时，后台周期性尝试连接盒子的当前地址。地址来自已认证蓝牙状态或本次配对结果；新 SSH 连接必须校验原盒子主机指纹，且模型列表请求通过后才能用于后续连接。保持原有本机回环端口，已有蓝牙流不迁移、不重发；新流使用已验证的 SSH 隧道。隧道失效后，新流继续使用蓝牙。取消或断开时终止后台尝试并关闭两个通道。

此机制不修改系统路由、代理或 Wi-Fi 配置，不能绕过无线网络的客户端隔离、跨子网访问限制或网络认证；Wi-Fi 不可达时仍使用蓝牙。它不依赖特定 SSID 或网段，也不保证所有网络上均能升级为 Wi-Fi。
