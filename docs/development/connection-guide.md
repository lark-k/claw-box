# 随身板子的连接引导（0.3.20）

适用场景：板子已部署并能对话，朋友带着同一块板子出差，用自己的 Windows 电脑和完整 APP 便携包，通过网线直连后使用。首次打开或连接失败时进入向导；已有用户从“连接与设置”直接进入。工作区只在首页选择，连接窗口不展示或修改工作目录。

## 朋友第一次连接

1. 解压完整包，运行 QuantumHarness.exe；板子接电，用网线连接电脑，电脑先连 Wi-Fi 或热点。关闭原电脑上的旧 APP。无需开发 SDK。
2. 设备地址按交付信息填写（当前示例 192.168.137.2），SSH 端口通常为 22，输入交付时的 root 密码，确认连接的是自己的板子。无需手填指纹，密码不保存。
3. 按右侧缺项提示处理网络。点“设置以太网 IP”直接进入专用弹窗，选连接板子的实体有线网卡。如果板子确为 192.168.137.2/24，电脑可用 192.168.137.1、掩码 255.255.255.0、网关留空。点击保存时 Windows 请求管理员权限。需要恢复时点击“恢复自动获取 IP”。
4. 点“设置网络共享”，打开所选上网网卡的属性。在“共享”页允许其他网络用户连接，目标选择插板子的以太网网卡。默认选择正在上网的 Wi-Fi，可展开“选择共享网络的上网网卡”更换；属性页无法打开时进入网络连接列表。Windows 共享可能调整以太网地址，返回向导会复查。
5. 输入完成、离开输入框后自动检查设备登录、板子持久 IP 配置、运行环境和模型服务网络。检查通过后点击“绑定并连接”，完成当前 Windows 用户的专用配对，返回首页选择工作区并发送一条消息验证对话。

电脑缺少连接组件时才显示“安装连接组件”，点击打开 Windows 可选功能，安装 OpenSSH 客户端即可，无需服务端。已安装时没有这个操作提示。

## 向导如何判断

0.3.19 起，打开向导时只检查电脑连接组件；第 2 项及后续项目显示等待。填写地址、端口、密码并勾选确认，离开输入框后，才开始以太网地址和设备端口检查。网络开始检查后每 3 秒复查；端口可达后自动执行一次只读密码登录检查，单次最长 45 秒。清空或修改输入、取消确认会重置后续状态并拒绝过期检查结果；相同密码失败后不会定时反复尝试。修正输入或明确点击检查可重试；处理已识别的网络故障并返回后也会复查。已有配对仍可不填密码，明确点击“使用已有配对连接”。

0.3.20 起，以太网地址项只检查实体 PCI/USB 网口，优先读取 Windows 保存的手动 IPv4 和掩码，过滤蓝牙、虚拟网卡及过滤器接口，简短显示一张网卡。手动配置为 `192.168.137.1 / 255.255.255.0` 时通过地址配置检查；链路、设备端口和模型网络由后续项目分别确认。软件不自动修改网卡。

保存 IP、网络地址变化或从共享设置返回时立即触发复查；已成功登录但模型网络不通时，也会继续只读重查模型服务端口。界面先显示检查中，收到结果后更新，不沿用旧的失败状态。系统实际应用共享可能需要时间，因此不承诺点击确定时网络已经可用；失败密码不会被定时反复尝试。

“板子固定 IP”卡片读取当前地址以及持久网络配置，只有能证明配置文件持久保存该地址才显示固定。支持 NetworkManager 和明确的 systemd-networkd 静态配置；DHCP、未识别网络后端、临时地址或未能证明的配置明确提示。这里不会自动改板子 IP，也不会仅凭能连接 192.168.137.2 就认定它固定。

当前板子的持久静态 IP 尚未实机核验：现有配对密钥仅允许受限隧道，不能读取管理配置。按用户选择，在新版 APP 输入密码后自动核验，也保留“检查板子配置”按钮。若显示 DHCP 或未确认，请由交付人员固定板子地址后复查。

模型网络检查只尝试连接已配置模型地址的 TCP 端口，不发送模型密钥或推理请求。端口可达不等于账号与模型可用，实际对话仍需首页验证。网络明确不可达时暂不允许绑定，先处理共享。

## 已有配对和安全边界

同一电脑或 Windows 用户换网络后，可留空密码，填写板子新地址，点击“使用已有配对连接”。软件核验仍为原板子后更新本机地址，保留密钥和凭据，不重新部署。换电脑或 Windows 用户需首次绑定；当前为单板子、单个工作客户端，不能让两台 APP 同时控制它。

软件自动获取首次设备公钥并固定身份。首次确认依赖用户连接正确的板子和可信直连环境，不能提供供应商身份认证。已保存的身份变化会阻止连接，不自动替换。日常隧道保持严格主机密钥检查。高级入口可导入当前用户可访问的已有配对文件和网关凭据。

自动检查不部署插件、不修改板子或电脑网卡。绑定先检查已有内容；匹配的插件、配对和聊天配置直接复用，仅补齐缺项或更新当前电脑的工作凭据。只有加载内容变化才重启网关，服务停止时启动它。网卡保存仍由用户明确点击。板子只收到受限密钥和 worker 凭据，审批凭据保留在 Windows；重连不重放文件任务，工作区和逐请求审批保持原行为。

成功配对并保存后，下次启动软件会自动尝试连接板子，无需再次填写密码或点击绑定。网络不可达、凭据失效或端口冲突时进入向导，修正后点击“使用已有配对连接”。APP 自己的后台执行器和隧道随 APP 关闭回收；不会终止外部程序。

0.3.20 起，正常退出先停止本地和板子端转发、断开 SSH，再回收执行器，释放本次 APP 的端口。连接中首页按钮显示“停止连接”，点击可取消；按钮下显示连接状态。

如果板子拒绝反向转发监听，软件仍会每隔 5 秒自动重试，最多额外尝试 12 次。突然断电可能留下旧 SSH 会话。持续失败时可在引导输入密码并明确点击“绑定并连接”：固定恢复程序只回收能证明来自当前电脑、且 Windows 已不存在对应活动 TCP 连接的旧 root SSH 隧道。活动连接、其他电脑或无法确认的占用者会保留并提示。无需删除配对；恢复不重放聊天或文件操作。边界见 [ADR 0013](../architecture/adr/0013-network-refresh-and-stale-tunnel.md)。

本地端口、SSH 密钥认证、板子身份、执行器数据目录占用和网络失败分别显示提示，不进入上述远端监听重试。只有聊天入口和工具反向转发均确认成功才显示连接成功。
