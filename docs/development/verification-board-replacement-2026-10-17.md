# 设置中的更换板子／重新绑定验收（2026-10-17）

版本：Quantum Harness 0.3.23。工作分支：main。边界见 ADR 0015。

左下角设置按钮改为独立菜单，分别提供“连接向导”和“更换板子／重新绑定”。后者先打开专用确认窗口，取消保留原连接，确认后停止使用旧配对并打开连接向导。聊天记录、工作区、用户文件和权限偏好保留。新配对使用独立目录，支持同地址不同身份的新板；旧身份和私钥不覆盖。未确认更换时，普通连接仍拒绝设备身份变化。

## 实机边界

本次没有对真实用户的配对文件、聊天、工作区或板子做换板操作，没有发送模型任务。SSH 与板端配置使用替身验证；没有第二块已烧录的新板，因此不把模拟的同 IP 换板测试当作实机烧录验收。后续镜像工作开始后，需用同 IP、不同 SSH 身份的新板，经 APP 确认换板、绑定、对话及具体请求审批后完成实际文件操作验收。

完整包位置：`artifacts/publish/QuantumHarness/0.3.23/win-x64/`；分发压缩包：`artifacts/releases/QuantumHarness-0.3.23-win-x64.zip`。首次使用本版本仍沿用原配对，只有明确确认换板才切换；APP 自身不执行镜像制作或烧录。
