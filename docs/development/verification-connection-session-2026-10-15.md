# 连接向导会话同步验证（2026-10-15）

版本：0.3.21，直接在主分支更新。

主窗口仍持有唯一的 RuntimeSession。向导订阅 ShellViewModel 的连接状态，在已连接时展示当前设备地址、端口、专用密钥认证、工具隧道与聊天入口，关闭后解除订阅。打开向导不重新连接，也不索要登录密码。成功连接清空向导内的临时密码及首次绑定确认。

同一 APP 会话的固定 IP、运行配置、模型网络检查按完整 SetupRequest（地址、端口、固定设备指纹）匹配，重开向导可显示“最近检查”。没有读取的管理信息显示“未核验”；不把聊天网关可访问等同于模型服务或固定 IP 已核验。此缓存仅在内存中，没有增加密码或管理数据落盘。

首页和向导均提供“断开连接”，调用已有 RuntimeSession.Dispose 释放转发和执行器，保留配对与历史，重置为逐请求审批，不自动重连或重发任务。仍有任务或审批时先停止并核对结果。连接失败、主动断开、外部连接状态变化同步到打开的向导，过期自动检查按版本丢弃；轮询使用连接版本与原执行器引用，断开后的旧结果不能覆盖新会话。

新增 5 项 STA 回归覆盖已连接打开、真实按钮所调用的断开路径、重开仍断开、旧检查晚到、外部重连、设备身份隔离、临时密码清空、配对/历史保留和任务中断开保护。既有检查顺序及绑定异常测试仍通过。
