# 桌面无线连接验收（2026-10-17）

版本：Quantum Harness 0.3.24，Windows 11 x64。板子及无线驱动基线见同日 `verification-wireless-services-2026-10-17.md`。本记录不包含密码、私钥或 token。

## 行为

- 设置菜单分别显示“有线连接”“无线连接”，用分隔线隔开“更换板子／重新绑定”。任务运行及待审批期间禁止切换。
- 首次连接提供连接方式选择，已有无线模式直接进入无线向导；有线向导保留 IP、共享及原配对功能。
- 无线向导通过 Windows 原生蓝牙发现设备、校验主机身份、读取/扫描 Wi-Fi、配置网络并获取无线地址。首次无线绑定提供固定初始化操作，已有配对换网复用原专用密钥。
- 无二维码或配对码；首次选择自己的未绑定设备代表首次信任。已有绑定拒绝不同主机身份。更换 Wi-Fi 不需要旧 Wi-Fi 或网线，电脑需与盒子在可互访的局域网。
- 切换前核验 SSH 主机身份；业务连接失败时恢复先前配对端点及连接方式。聊天及工作区不变。响应未知时不会自动重放配网写入。
- 自包含便携包包含原生 Windows 蓝牙投影，无需最终用户安装 Python 或 SDK；SSH 连接仍使用 Windows OpenSSH Client。

## 验证

- C# 原生协议客户端与真实 Python 服务互操作：首次认证、加密状态读取、重复序号拒绝通过。
- Windows 原生 BLE 在实机通过发现、既有身份认证、状态读取、扫描、实际 Wi-Fi 配置和固定 `desktop_setup` 初始化操作。此项为显式启用的实机测试，普通 CI 默认跳过。
- `scripts/ci/Verify.ps1`：桌面 182 通过、3 个实机测试默认跳过；执行器 63 通过、1 个可选隔离测试跳过；插件 11 通过；Python 64 通过。构建无警告或错误。
- `scripts/ci/Test-DesktopPublish.ps1 -SideBySide` 验收真实自包含 EXE：设置菜单、连接方式选择、无线设备/网络/就绪状态、较小窗口，以及原有线和换板流程。

## 范围

实机网络验证使用用户授权的一个 WPA PSK 网络。没有清除用户真实配对以模拟全新出厂设备；首次 claim 由协议互操作及板端测试覆盖。蓝牙服务以外的路由器隔离、企业认证或网页认证网络不在自动配网支持范围内。断开蓝牙后可重新搜索，或使用高级入口输入已联网盒子的地址，经原身份核验连接。
