Quantum Harness Windows x64 测试安装包

双击 quantum-harness-0.2.2-alpha.2-win-x64-unsigned.exe，按向导选择目录安装，从开始菜单启动 Quantum Harness。
包含桌面工具、插件及 Office 运行库，无需另装 Node.js 或 Python。
软件名称、任务栏、图标、首页及侧栏已改为 Quantum Harness；官方登录改为“连接盒子”。

模型：首次使用请在“设置 → 模型”配置自己的 OpenAI 兼容服务和 API Key。
本包不包含开发者的模型密钥、网关令牌或聊天记录。
盒子：当前只保存待连接的地址和 SSH 端口；实体盒子配对及转发尚未启用。

升级：后续相同应用标识的新版安装包可覆盖安装，不需要先卸载；聊天、配置和工作区独立于程序目录。
目前不提供应用内自动检查或下载更新。涉及数据格式变化的新版仍需单独做迁移验收。

这是未签名测试版本，产品版本 0.2.2-alpha.2。正式公开发行前仍需代码签名。
同目录 SHA256SUMS.txt 用于核对安装包传输完整性。
